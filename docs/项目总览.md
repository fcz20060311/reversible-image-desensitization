# 项目总览：我们到底在做什么

## 一句话

**把你的论文核心方法，升级成一个能用的 AI 系统。**

论文是「心脏」，项目是「心脏 + AI 大脑 + 身体」。

## 论文 vs 项目

```
你的论文（已写完）
└─ 一个方法：可逆图像脱敏（打码还能还原）
   实现：MATLAB 实验脚本
   证明：实验数据

          ↓ 搬进来，再加两块

我们的项目：AI 可逆脱敏系统
├─ ① 可逆脱敏核心    ← 就是你论文（用 Python 重写）
├─ ② AI 自动检测      ← 论文没有 ⭐ 新增
└─ ③ Web 系统         ← 论文没有 ⭐ 新增
```

## 三块分别是什么

| 模块 | 是什么 | 来自哪 |
|---|---|---|
| ① 可逆脱敏核心 | 打码 + 无损还原 | **你的论文** |
| ② AI 自动检测 | 自动找出人脸 / 文字 | 新增——「AI」体现在这 |
| ③ Web 系统 | 上传图片、看结果、授权还原 | 新增——「系统」体现在这 |

## 为什么要加 ②③

- **论文 = 科研**：证明「这个方法管用」 → 够保研用
- **项目 = 产品**：能 demo、能给人用、能讲工程故事 → 实习 / 就业需要

只有 ① 是「论文代码复现」；加上 ②③ 才叫「一个 AI 系统」。
