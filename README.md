# 可逆图像脱敏系统（Reversible Image Desensitization System）

> 一句话：一个「打了码还能无损还原」的智能图像脱敏系统。

## 它解决什么问题

云相册、社交平台、图像管理系统需要同时满足三个互相冲突的需求：

1. **隐藏敏感细节**（人脸、文字、车牌等隐私）
2. **保留粗粒度视觉线索**（还能看出「这是谁、在哪、拍的啥」）
3. **支持授权无损恢复**（输密码能还原原图）

普通马赛克只能做到 1；完全加密只能做到 3。本系统用「AI 自动检测 + 可逆脱敏」同时做到三者。

## 核心能力

- **AI 自动检测敏感区**：用预训练模型自动找出人脸、文字等该遮挡的区域
- **可逆脱敏**：对敏感区做内容感知分区 + 可逆变换，保留轮廓、遮蔽细节
- **无损恢复**：授权后逐像素还原原图

## 为什么重要（社会价值与落地场景）

**核心矛盾**：《个人信息保护法》要求平台保护用户隐私，但平台又需要「用」这些图片（浏览、检索、审核、训练 AI）。完全加密会让图片「不可用」，普通打码则「不可逆」——本系统用「可逆脱敏」同时满足隐私与可用。

**落地场景**：

- **AI 训练数据合规**：训练大模型 / 自动驾驶需海量图片，先脱敏再训练，合规不侵权
- **内容审核**：审核员判违规，但不接触当事人人脸 / 文字隐私
- **执法取证**：平时脱敏保护路人隐私，办案时授权无损还原证据
- **云相册 / 网盘**：平台存脱敏图（可浏览），授权看原图，不碰明文
- **医疗影像**：教学科研用，患者身份脱敏、病灶轮廓保留

## 架构

```
Vue 前端
  └─ Java Spring Boot 后端（上传 / 任务 / 授权）
       └─ Python AI 服务（检测 + 脱敏 + 恢复）
```

## 快速运行

```bash
cd python
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
# 把一张照片放到 test_picture/sample.jpg
python demo.py
```

产出三张图：原图 / 加密图（花了但轮廓还在）/ 解密图（与原图逐像素一致）。
